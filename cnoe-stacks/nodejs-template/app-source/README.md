# {{ appName }}

{{ description }}

A Node.js 20 HTTP service generated by the Golden Path AI-powered onboarding
agent. It ships with OpenTelemetry tracing/metrics and a Prometheus-compatible
`/metrics` endpoint out of the box.

## Endpoints

| Path        | Method | Purpose                                                      |
|-------------|--------|--------------------------------------------------------------|
| `/`         | GET    | JSON greeting (`app`, `message`, `version`).                 |
| `/healthz`  | GET    | Liveness probe target. Returns `{"status":"ok"}`.            |
| `/readyz`   | GET    | Readiness probe target. Returns `{"status":"ok"}`.           |
| `/metrics`  | GET    | Prometheus exposition format (default + `http_requests_total`). |

## Run locally

```bash
npm ci
npm start
# in another shell
curl http://localhost:8080/
curl http://localhost:8080/metrics
```

## Environment variables

| Variable                         | Default                                                            | Purpose                                |
|----------------------------------|--------------------------------------------------------------------|----------------------------------------|
| `PORT`                           | `8080`                                                             | TCP port the HTTP server binds.        |
| `APP_NAME`                       | `{{ appName }}`                                                    | Surfaced in the `/` response.          |
| `OTEL_EXPORTER_OTLP_ENDPOINT`    | `http://otel-collector.observability.svc.cluster.local:4318`       | OTLP/HTTP collector base URL.          |
| `OTEL_SERVICE_NAME`              | `{{ appName }}`                                                    | Resource attribute on every span.      |

OpenTelemetry SDK init is wrapped in `try/catch` so the HTTP server still starts
when the collector is unreachable -- useful for local dev.

## Container

```bash
docker build -t {{ appName }}:dev .
docker run --rm -p 8080:8080 {{ appName }}:dev
```

The image is multi-stage, runs as the non-root `node` user, and includes a
`HEALTHCHECK` that hits `/healthz`.
